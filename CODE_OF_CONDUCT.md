# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussion technical, and
accept that a maintainer may decline a change that does not fit the project's
deliberately narrow scope (see `specs/01-product-spec.md`).

Report unacceptable behaviour to the maintainer via a private GitHub security
advisory or direct message. Reports are handled confidentially, and the
maintainer will respond as promptly as a volunteer project allows.
